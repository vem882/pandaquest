# PandaQuest/Textures

Generated by `python3 tools/make_textures.py` (pure Python, no PIL). Do not edit the
`.tga` files by hand - change the shape definitions in the script and regenerate.
`python3 -m pytest tools/tests/test_textures.py` validates the headers and checks that
the committed files match a fresh generation.

Format: uncompressed 32-bit BGRA TGA (image type 2, descriptor 0x08 = 8 alpha bits,
bottom-left origin / rows stored bottom-up), power-of-two sizes, anti-aliased (4x4
supersampling). Transparent pixels carry the colour of the nearest opaque pixel so
bilinear filtering does not create dark fringes. All pins have a dark outline for
readability on the world map and minimap.

Path prefix in Lua: `"Interface\\AddOns\\PandaQuest\\Textures\\"`.


Notes for users of the textures:

- `arrow.tga` is square and centred; draw it in a square texture region (e.g. 42x42 inside
  the 56x42 arrow frame) so `SetRotation` does not distort it. The fill is pure white so the
  red->yellow->green bearing gradient is applied with `SetVertexColor`; the outline stays dark.
- `arrow_glow.tga` is white with a radial alpha falloff; tint it and fade its alpha for the
  arrival flash. Use `SetBlendMode("ADD")` for a stronger glow.
- Pins are designed for 24-32 px on the world map and 12-16 px on the minimap; the outline
  keeps them readable when scaled down.
- `Icons/route.tga` (8x8 dot) is suitable for drawing route lines with many small textures.
- `Icons/tracker_*.tga` are plain UI button glyphs for the tracker/options frames.
