# PandaQuest/Textures/Icons - licensing

The `.tga` files in this directory are copied unchanged from Questie
(`Icons/` directory, https://github.com/Questie/Questie), which in turn copied them
from pfQuest (https://github.com/shagu/pfQuest) with the author's permission.
Only the files that Questie's `Icons/LICENSE.md` lists as MIT-licensed are included:

* `fav.tga` - 32x32 star (favourite/marker)
* `icon_alliance.tga` - 32x32 Alliance crest (faction hints in tooltips/options)
* `icon_horde.tga` - 32x32 Horde crest
* `loot_mono.tga` - 64x64 white monochrome loot bag (tintable)
* `node_cut.tga` - 32x32 hollow node dot (minimap/cluster marker)
* `node.tga` - 32x32 filled node dot
* `object_mono.tga` - 64x64 white monochrome object/gear (tintable)
* `route.tga` - 8x8 dot for drawing route lines
* `slay_mono.tga` - 64x64 white monochrome crossed swords (tintable)
* `startend.tga` - 32x32 quest start + end marker
* `startendstart.tga` - 32x32 quest start marker (unfinished chain)
* `tracker_clean.tga` - 32x32 tracker button: clean
* `tracker_close.tga` - 32x32 tracker button: close
* `tracker_database.tga` - 32x32 tracker button: database
* `tracker_giver.tga` - 32x32 tracker button: quest giver
* `tracker_quests.tga` - 32x32 tracker button: quests
* `tracker_search.tga` - 32x32 tracker button: search
* `tracker_settings.tga` - 32x32 tracker button: settings

Every other Questie icon is "all rights reserved" and is NOT shipped with PandaQuest;
PandaQuest's own map pins are generated by `tools/make_textures.py` instead.
