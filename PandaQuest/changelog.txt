Under a data change, indented lines say what changed: "  - coordinates: 3 spawn points added in Badlands".
Older data syncs: see each version's GitHub release notes and https://pd.zroot.it/changelog

0.2.246
- packaging - the CurseForge package made from the repository carries all four games again
  - every game's TOC is kept in the repository, written from one template
  - the Classic Era, TBC Anniversary and Forever databases are no longer left out of it

0.2.242
- core - new files of an update made while the game ran did not load: PandaQuest now says to restart
  - after 0.2.236 that hid the flight times and the quest mob marks; /reload is not enough
- quest mobs - kill-credit objectives mark their own group, not another creature of the quest twice
- quest mobs - talk-to NPCs, turn-in NPCs (?) and givers with a quest for you (!) are marked too
  - each with its own switch; the kill mark is now the kill pin by default

0.2.241
- games - PandaQuest runs in Classic Era, TBC Anniversary and WoW Forever, beside MoP Classic
  - one download: each game's TOC loads only its own quest database
  - WoW Forever's quest database comes with its launch (4 November 2026); one line says so
  - the MoP Classic TOC and database are unchanged
- games - features a game does not have stay off there: archaeology and the dig-site bar are MoP's
  - in WoW Forever the recipe scanner and kill counts from the combat log are off for now
- saved data - MoP data copied into another game's folder is set aside whole, never deleted
- compatibility - WoW Forever's quest log, spells, reputation and tooltips are bridged
  - Skyborne quests (race bits 32 and 33) are matched correctly

0.2.240
- auction - the auction house scan, mailbox sales and auction tooltip prices are removed
  - your saved auction data (PandaQuestAH) is kept: still declared, never read or written
  - /pq scan alone now points at /pq scan professions; professions and archaeology are unchanged

0.2.239
- docs - README brought up to date: flight times, quest mobs, site links, install and privacy

0.2.236
- flight - the bar shows the time left and fills from takeoff, also on a route you never flew

  - else an estimate from the path's length, marked "(estimated)"; hover the bar: arrival time
- flight - the flight master's tooltip shows the expected time before the first flight
- database - flight times from the portal (Database/Overrides/Flights.lua)
- quests - mobs your unfinished quests need killed get a quest mark on their nameplate
  - also the droppers of quest items; tooltip line "Quest: <title> (3/8)"; optional health bar tint
  - Options > Navigation > Quest mobs: icon, size, tint, tooltip; Options > Modules switches it off

0.2.235

- options - categories with icons, sub-tabs, a search box and a reset button per category
- ui - the window remembers its place, size and scale per profile; Esc closes it
