PandaQuest changelog. Newest version first, one short line per change.
Data changes read "<kind> <id> - <name> - added|updated|fixed|removed" (kinds: quest, npc, object, item).
Everything else reads "<area> - <what changed>".
Under a data change, indented lines say what changed: "  - coordinates: 3 spawn points added in Badlands".
Older data syncs: see each version's GitHub release notes and https://pd.zroot.it/changelog

0.2.236
- flight - the bar shows the time left and fills from takeoff, also on a route you never flew
  - the time is your own median of 2+ flights, else all players' measured time from the portal
  - else an estimate from the path's length, marked "(estimated)"; hover the bar: arrival time
- flight - the flight master's tooltip shows the expected time before the first flight
- database - flight times from the portal (Database/Overrides/Flights.lua)
- quests - mobs your unfinished quests need killed get a quest mark on their nameplate
  - also the droppers of quest items; tooltip line "Quest: <title> (3/8)"; optional health bar tint
  - Options > Navigation > Quest mobs: icon, size, tint, tooltip; Options > Modules switches it off

0.2.235
- ui - one PandaQuest window: Quests, Status, Options, About & Help and Performance
- options - categories with icons, sub-tabs, a search box and a reset button per category
- ui - the window remembers its place, size and scale per profile; Esc closes it
- options - Release notes, About & Help and Performance pages; the logo is the portal's, made round

0.2.234
- ui - /pq opens PandaQuest: the quest browser with every quest; its Settings button opens the rest
- ui - a quest's page and right-click menu: navigate, hide or show, show on map, PandaQuest link
- ui - links go to the quest's page on the PandaQuest portal (pd.zroot.it) instead of Wowhead
- options - new sections: Status, Hidden quests, Moving frames; privacy text under Sync
- options - Advanced prints a database entry and lists every chat command
- commands - every old command still works; /pq help is one line, /pq help all lists them

0.2.233
- core - every part of PandaQuest is an Ace3 module, set up and started in the same order as before
- options - new Modules section: switch a part of the addon off completely, saved in the profile
- options - /pq config [section] [option] [value] changes any setting from chat
- core - timers that counted every frame now fire only when due (map pins, tooltips, scans)
- languages - a text a language does not translate now reads in English, not the language before
- saved data - nothing is moved or renamed; module switches are new keys only
